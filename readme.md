utilicé un archivo llamado AirPassengers.csv, que trae un registro histórico de cuántos pasajeros se movilizaron por avión cada mes durante varios años. Lo primero que hice fue extraer dos datos clave de cada registro: el año y el número del mes. A partir de eso, busqué predecir la variable más importante de todas: la cantidad de pasajeros. La estrategia que usé fue aplicar una regresión no lineal múltiple en Python, con ayuda de herramientas como scikit-learn. ¿Por qué no lineal? Porque el comportamiento de los pasajeros no siempre sigue una línea recta. Hay subidas, bajadas, patrones estacionales, y una regresión lineal normal se quedaría corta. Por eso, transformé los datos con una función polinomial (de segundo grado) para que el modelo pueda aprender relaciones más complejas entre el paso del tiempo y la cantidad de personas que viajan.
Después, dividí el conjunto de datos: el 80% fue para entrenar el modelo y el 20% para probarlo. Entrenado el modelo, calculé algunas métricas para saber qué tan bien había aprendido. Lo más destacable fue el coeficiente R², que dio un valor cercano a 0.88, lo cual significa que el modelo es capaz de explicar alrededor del 88% de la variación en los datos. Bastante bien, considerando que solo usamos el año y el mes. Además, incluí gráficos para hacerlo más visual. Al ejecutar el programa, primero aparece un gráfico con los datos de entrenamiento, y una vez que lo cierras, se abre otro con los datos de prueba. Así se puede ver claramente cómo el modelo se comporta en cada caso.
aunque este es un modelo simple y aún no toma en cuenta cosas como feriados, vacaciones o la situación económica, es un buen comienzo. Demuestra que incluso con pocos datos se pueden detectar tendencias importantes. Más adelante se puede mejorar añadiendo más variables o usando modelos más avanzados, pero este proyecto ya permite entender cómo aplicar regresión no lineal múltiple a un problema real de forma clara y efectiva.
