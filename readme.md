Este proyecto nace con la idea de predecir cuántos pasajeros aéreos viajan cada mes, utilizando simplemente el año y el mes como referencia. Para lograrlo, trabajé con un archivo llamado AirPassengers.csv, que contiene datos históricos de la cantidad de pasajeros registrados mes a mes durante varios años. A partir de esos datos, extraje dos variables importantes: el año (Year) y el número del mes (Month_num), que se usan como entrada para el modelo de predicción. La variable que queremos predecir es la cantidad de pasajeros (#Passengers).
Con esa información, apliqué una regresión lineal múltiple utilizando Python y la librería scikit-learn. Dividí los datos en dos partes: el 80% para entrenar el modelo y el 20% para ponerlo a prueba. El modelo aprendió la relación entre el paso del tiempo y el número de pasajeros, y luego lo evalué con métricas como el error cuadrático medio MSE y el coeficiente de determinación R². Este último fue bastante bueno, alcanzando un valor cercano a 0.88, lo que significa que el modelo logra explicar casi el 88% de la variación en los datos. En otras palabras, entiende bastante bien el comportamiento general de los pasajeros a lo largo del tiempo.
También incluí visualizaciones para hacerlo más intuitivo: primero se muestra un gráfico con los datos de entrenamiento para ver cómo el modelo aprendió, y cuando se cierra ese, aparece el gráfico con los datos de prueba para ver cómo se comporta con datos nuevos. Esto permite ver claramente si el modelo está funcionando bien o no.
Aunque es un modelo sencillo, es bastante útil para detectar tendencias. Sabemos que no todo se puede predecir solo con el año y el mes hay otros factores como feriados, vacaciones, economía, pero aún así el modelo da resultados bastante buenos. Más adelante, se podría mejorar este proyecto usando modelos más complejos o añadiendo más variables, pero este es un excelente punto de partida para entender cómo funciona una regresión lineal múltiple aplicada a un caso real.
